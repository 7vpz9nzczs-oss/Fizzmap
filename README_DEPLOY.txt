FIZZMAP — PWA Quick Start

1. Lade alle Dateien dieses Verzeichnisses in das Root-Verzeichnis eines GitHub-Repos.
2. GitHub → Settings → Pages → Deploy from a branch → main / (root).
3. HTTPS-Link in Safari auf dem iPhone öffnen.
4. Safari Teilen → Zum Home-Bildschirm → Hinzufügen.
5. MY FIZZ → JSON-Backup regelmäßig exportieren.

Die Demo-Drinks sind fiktiv. Alle echten persönlichen Daten bleiben lokal.
Offline funktioniert die PWA erst nach mindestens einem vollständigen Online-Laden.
